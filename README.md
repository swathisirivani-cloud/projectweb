## ✨ Key Features

1. **Clean Semantic Architecture:** Structured with accessible HTML5 landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
2. **Modern Gradient Header & Hero:** Subtle radial backdrop glow and gradient typography highlight for an inviting first impression.
3. **Dark / Light Mode Toggle:** Seamless theme switcher in the header with persistent memory using browser `localStorage`.
4. **Smooth Navigation & Scrolling:** Instant, silky navigation to `#about`, `#skills`, `#projects`, and `#contact` sections.
5. **3 Featured Project Showcases:**
   - **Portfolio Planner:** Interactive planning and code-generation tool for engineering students.
   - **Arcade Game:** 2D interactive arcade game with collision logic, score tracking, and keyboard loops.
   - **day4hack:** 24-hour hackathon prototype built through collaborative teamwork.
6. **Floating "Back to Top" Button:** Automatically fades in when scrolling past 300px and returns to top with a smooth glide.
7. **One-Click Email Copy:** Built-in clipboard handler with visual feedback (`"Copied! ✓"`).
8. **Fully Mobile-Responsive:** Built with CSS Flexbox & CSS Grid, adapting seamlessly to mobile phones, tablets, and laptops.

---

## 🛠 Technologies Used

- **HTML5:** Semantic page structure, meta tags, and accessibility attributes.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, media queries, and smooth transition curves.
- **JavaScript (ES6+):** DOM manipulation, event listeners, Clipboard API, and `localStorage` state management.
- **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) and JetBrains Mono via Google Fonts.
